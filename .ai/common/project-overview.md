# プロジェクト概要

## 基本情報

Tools.tomacheese.com は、Nuxt.js v3 で構築されたプライバシー重視の Web ツールサイトです。すべてのツールは完全にクライアントサイドで動作し、サーバー通信は一切行いません。

## 技術スタック

- **フレームワーク**: Nuxt.js v3 (3.13.2)
- **言語**: TypeScript
- **パッケージマネージャー**: pnpm 8.15.9
- **Node.js**: v20.15.1 以上
- **スタイリング**: カスタム CSS（レスポンシブ対応）
- **テスト**: Vitest（単体テスト）+ Playwright（E2E テスト）

## 基本要件

### プライバシーファースト

- **100% クライアントサイド**: すべてのツールは外部 API を使用せずブラウザ内で動作する必要があります
- **データ送信禁止**: ユーザーのデータをサーバーに送信してはいけません
- **ローカル処理**: すべての計算・変換・処理はブラウザ内で完結させてください

### セキュリティ要件

- **外部通信禁止**: API コール、データ送信の禁止
- **ローカルストレージ**: 必要最小限の使用
- **XSS 対策**: ユーザー入力の適切なサニタイズ
- **暗号化**: 必要に応じてクライアントサイド暗号化
- **履歴削除**: ブラウザ履歴にセンシティブデータを残さない

## パフォーマンス要件

### Lighthouse スコア目標

- **Performance**: 90 以上
- **Accessibility**: 100
- **Best Practices**: 100
- **SEO**: 100

### 最適化指針

- **コード分割**: ツールごとに適切な分割
- **画像最適化**: WebP 形式を優先
- **CSS 最適化**: 未使用 CSS の削除
- **JavaScript 最適化**: Tree shaking の活用

## 禁止事項

- **外部 API の使用**: DNS 検索、Whois、IP 検索、サイト速度テストなど
- **サーバーサイド処理**: Node.js サーバー機能の使用
- **データ送信**: ユーザーデータの外部送信
- **大きな依存関係**: 不要なライブラリの追加

## 推奨事項

- **段階的実装**: 小さな単位での実装
- **テストファースト**: テスト駆動開発
- **レスポンシブ**: モバイル対応の徹底
- **アクセシビリティ**: WAI-ARIA ガイドライン準拠
