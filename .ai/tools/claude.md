# Claude Code 使用ガイド

このファイルは、開発者が Claude Code（claude.ai/code）を使ってこのプロジェクトで効果的に開発を行うためのガイドです。

## Claude Code とは

Claude Code は、プロジェクト全体のコンテキストを理解して開発支援を行う AI ツールです。コードベース全体を把握し、一貫性のある実装を支援します。

## セットアップ方法

1. [claude.ai/code](https://claude.ai/code) にアクセス
2. プロジェクトのルートディレクトリをアップロード
3. Claude Code がプロジェクト構造を解析するまで待機

## 効果的な使用方法

### プロジェクト理解の活用

Claude Code の強みは、プロジェクト全体を理解していることです：

```
「このプロジェクトのアーキテクチャを教えて」
「新しいツールを追加するにはどうすればいい？」
「既存のツールと同じパターンで実装して」
```

### 具体的な開発タスクでの活用

#### 新しいツールの作成

```
「Base64 エンコード/デコードツールを作成してください。
既存のツールと同じディレクトリ構造とスタイルで実装してください。」
```

#### バグ修正

```
「この関数でエラーが発生しています。
他の類似した実装を参考に修正してください。」
```

#### リファクタリング

```
「このコンポーネントを TypeScript の型安全性を向上させながら
リファクタリングしてください。」
```

## ベストプラクティス

### 質問の仕方

1. **具体的な要求**: 「何を」「どのように」を明確にする
2. **コンテキスト提供**: 関連するファイルや機能を言及する
3. **制約の明示**: プライバシー要件など重要な制約を伝える

### 効率的な作業フロー

1. **全体把握**: まずプロジェクト構造を確認
2. **段階的実装**: 小さな単位で実装と確認を繰り返す
3. **テスト駆動**: 実装と並行してテストも作成
4. **継続的確認**: 既存コードとの一貫性を保つ

## プロジェクト固有の注意点

### 必須要件

- **完全クライアントサイド**: 外部 API は使用不可
- **プライバシーファースト**: データの外部送信は禁止
- **TypeScript 必須**: 型安全性を重視

### 推奨パターン

- 既存の `utils/` ディレクトリの関数を参考にする
- `useTools.ts` への新ツール登録を忘れない
- レスポンシブデザインの考慮
- アクセシビリティへの配慮

## テスト戦略

Claude Code にテストの作成も依頼できます：

```
「この関数の単体テストを Vitest で作成してください」
「E2E テストも含めて包括的なテストを作成してください」
```

### テスト実行コマンド

```bash
# 単体テスト
pnpm test
pnpm test:watch
pnpm test:coverage

# E2E テスト
pnpm test:e2e
pnpm test:e2e:ui
```

## トラブルシューティング

### よくある問題

1. **型エラー**: 既存のコードを参考に型定義を確認
2. **スタイルの不一致**: 他のツールのスタイリングを参考にする
3. **レスポンシブ対応**: TailwindCSS のレスポンシブクラスを活用

### 解決のコツ

- エラーメッセージと関連コードを Claude Code に共有
- 「他の類似した実装はどうなっている？」と質問
- 段階的にデバッグして問題を特定
