# Claude Code 固有設定

このファイルは Claude Code（claude.ai/code）用の固有設定を記載しています。

## Claude Code の特徴

Claude Code は、プロジェクト全体のコンテキストを理解して開発支援を行う AI ツールです。

## 使用方法

1. プロジェクトのルートディレクトリで Claude Code を起動
2. ファイル構造とコードを解析
3. 開発タスクに応じた支援を提供

## Claude Code 向け重要事項

### コンテキスト理解

- プロジェクト全体の構造を把握してから作業を開始してください
- 既存のコードパターンを踏襲してください
- 段階的な実装を心がけてください

### 実装時の注意点

- 外部 API を使用したツールの実装は避けてください
- クライアントサイドのみで動作するツールを実装してください
- TypeScript の型安全性を重視してください

### 推奨作業フロー

1. 要求の理解と既存コードの調査
2. 実装計画の策定
3. ユーティリティ関数の実装
4. Vue コンポーネントの実装
5. テストの作成
6. 統合とテスト

### 特に注意すべき点

- `useTools.ts` へのツール登録を忘れないでください
- レスポンシブデザインを考慮してください
- アクセシビリティに配慮してください
- 既存のスタイルパターンを参考にしてください

## 単体テストの実行

```bash
# 特定のテストファイルの実行
pnpm test path/to/test.test.ts

# ウォッチモードでのテスト
pnpm test:watch
```

## E2E テストの実行

```bash
# 特定のE2Eテストの実行
pnpm test:e2e path/to/test.spec.ts

# UIモードでのテスト
pnpm test:e2e:ui
```
