# GitHub Copilot 固有設定

このファイルは GitHub Copilot 用の固有設定を記載しています。

## GitHub Copilot の特徴

GitHub Copilot は、コード補完とリアルタイムな開発支援を提供する AI ツールです。

## 効果的な使用方法

### コメント駆動開発

関数やコンポーネントの目的をコメントで記述してから実装してください：

```typescript
// BMI を計算し、分類も含めて返す関数
export function calculateBMI(weight: number, height: number): BMIResult {
  // 実装が自動補完される
}
```

### 型定義の活用

TypeScript の型定義を先に作成することで、より適切な補完が得られます：

```typescript
interface BMIResult {
  bmi: number
  category: string
  isHealthy: boolean
}
```

## Copilot 向け重要事項

### プロンプト設計

- 実装したい機能を日本語コメントで詳細に記述
- 期待する入力と出力を明確に示す
- エラーハンドリングの要件も記述

### コード品質向上

- Copilot の提案を盲目的に受け入れず、コードレビューを実施
- プロジェクトの命名規則に合わせて調整
- TypeScript の型安全性を確保

### テスト駆動開発

- テストケースをコメントで記述してからテストコードを生成
- テストが通ることを確認してから本実装を行う

## 推奨ワークフロー

1. **仕様の整理**: 日本語コメントで要件を明確化
2. **型定義**: インターフェースや型の定義
3. **テスト実装**: 期待する動作のテストケース作成
4. **本実装**: Copilot の補完を活用して実装
5. **レビュー**: 生成されたコードの品質確認

## 注意事項

### セキュリティ

- API キーやシークレット情報を含むコードは生成させない
- 外部サービスへの通信コードは避ける

### プライバシー

- ユーザーデータの処理は慎重に実装
- クライアントサイドのみで完結するよう確認

### パフォーマンス

- 大量のデータ処理では効率的なアルゴリズムを選択
- 不要な再レンダリングを避ける最適化を実装
