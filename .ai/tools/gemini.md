# Gemini CLI 固有設定

このファイルは Gemini CLI 用の固有設定を記載しています。

## Gemini CLI の特徴

Gemini CLI は、コマンドライン環境での開発支援とコード生成を提供する AI ツールです。

## 使用方法

```bash
# プロジェクトディレクトリで Gemini CLI を起動
gemini --project .

# 特定のファイルに対してコード生成
gemini generate --file src/utils/new-tool.ts

# インタラクティブモードで開発支援
gemini interactive
```

## Gemini CLI 向け重要事項

### プロンプト設計

- 具体的で明確な指示を提供
- コンテキスト情報（プロジェクトの性質、制約）を含める
- 段階的なタスクに分割して実行

### コード生成のベストプラクティス

1. **関数単位での生成**: 大きなコンポーネントを一度に生成せず、関数やメソッド単位で実装
2. **型安全性の確保**: TypeScript の型定義を含めた生成を要求
3. **テストファーストアプローチ**: テストコードを先に生成してから実装

### 効果的なプロンプト例

```
「BMI計算ツール用のユーティリティ関数を作成してください。
- 体重（kg）と身長（cm）を受け取る
- BMI値と健康状態の分類を返す
- TypeScriptで型安全に実装
- エラーハンドリングを含める
- JSDocコメントを日本語で記述」
```

## 推奨ワークフロー

### 1. 要件分析

```bash
gemini analyze "このプロジェクトに新しいツールを追加したい。要件を整理してください。"
```

### 2. 設計段階

```bash
gemini design "○○ツールのアーキテクチャを設計してください。"
```

### 3. 実装段階

```bash
gemini implement "設計に基づいてコードを生成してください。"
```

### 4. テスト作成

```bash
gemini test "実装した機能のテストコードを作成してください。"
```

## 注意事項

### プロジェクト制約の遵守

- 外部 API を使用しないクライアントサイドツールであることを強調
- プライバシーファーストの原則を明示
- レスポンシブデザインの要件を含める

### 品質保証

- 生成されたコードは必ずレビューを実施
- TypeScript の型チェックを通すことを確認
- 既存のコードスタイルに合わせて調整

### パフォーマンス考慮

- 重い計算処理の場合は Web Workers の使用を検討
- メモリ効率的なアルゴリズムを選択
- 必要に応じて遅延読み込みを実装

## CLI 環境での開発支援

### ファイル監視とリアルタイム支援

```bash
# ファイル変更を監視しながら開発支援
gemini watch --directory src/

# 特定のパターンのファイルのみ監視
gemini watch --pattern "*.vue,*.ts"
```

### バッチ処理

```bash
# 複数ファイルの一括処理
gemini batch --task "コメントの翻訳" --files "src/**/*.ts"

# テストファイルの一括生成
gemini generate-tests --source "src/utils/" --output "tests/"
```
