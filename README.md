# tools.tomacheese.com

プライバシー重視の Web ツールサイトです。現在 **65個のツール** を提供し、すべてクライアントサイドで動作します。

## ✨ 特徴

- **100% プライバシー保護**: データはブラウザ内でのみ処理、外部送信なし
- **完全無料**: すべてのツールが無料で利用可能
- **レスポンシブ対応**: 全デバイスで快適に動作
- **高速処理**: サーバー通信なしで瞬時に結果表示

## 🛠️ 技術スタック

- **Nuxt.js v3.17.7** (SSR 無効)
- **TypeScript** (厳格な型チェック)
- **Tailwind CSS** + カスタム CSS
- **Vitest** + **Playwright** (テスト)

## 🚀 開発

```bash
# 依存関係インストール
pnpm install

# 開発サーバー起動
pnpm dev

# テスト実行
pnpm test && pnpm test:e2e

# ビルド
pnpm generate
```
