# 実装済みツールの自動検出システム

このプロジェクトでは、ビルド時に `pages/tools/` ディレクトリをスキャンして、実装済みツールを自動検出するシステムを導入しています。

## 仕組み

1. **ビルドフック**: `nuxt.config.ts` の `hooks['build:before']` でビルド開始時にツールを検出
2. **ファイルスキャン**: `pages/tools/` ディレクトリの `.vue` ファイルをスキャン
3. **プラグイン生成**: 検出されたツールIDリストを含むNuxtプラグインを動的生成
4. **自動提供**: 生成されたプラグインがランタイムで実装済みツールリストを提供

## 新ツールの実装手順

1. `pages/tools/` ディレクトリに新しい `.vue` ファイルを作成
2. ツールの定義を `composables/useTools.ts` の `allTools` 配列に追加
3. ビルド時に自動的に実装済みツールとして検出・表示される

## メリット

- ✅ 手動でのツールリスト管理が不要
- ✅ ヒューマンエラーによる管理ミスを防止
- ✅ 新ツール実装時の作業を簡素化
- ✅ Vue Router警告を完全に解消
- ✅ ファイル存在ベースの確実な検出

## 技術詳細

- **検出方法**: ファイルシステムをスキャンして `.vue` ファイルの存在を確認
- **生成ファイル**: `plugins/implemented-tools.client.ts`（ビルド時に自動生成・更新）
- **型安全性**: TypeScript の型定義により型安全な実装済みツール管理

このシステムにより、スクリプトの手動実行が不要となり、ビルド時に完全自動化されたツール管理を実現しています。
